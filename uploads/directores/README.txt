Carpeta de imágenes de directores de obra
=========================================

- Las imágenes que subes desde el catálogo se guardan aquí con nombre tipo:
  director-1234567890-123456789.jpg

- Si en la base de datos tienes rutas antiguas (ej. 201001081343220.726.JPG),
  copia esos archivos .JPG a ESTA misma carpeta con el mismo nombre que en la BD.

- La URL que usa la app es: /uploads/directores/NOMBRE_ARCHIVO
  Ejemplo: /uploads/directores/201001081343220.726.JPG

- Ruta completa en este proyecto: obras-backend/uploads/directores/
